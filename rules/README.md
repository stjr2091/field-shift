# Rules

`rules.csv` is the single source of truth for crop rules.

Conventions:

- Every row carries a source in the `source` column, with a link in `source_url` where one exists.
- Where a rule has no source, `source` is set to `unknown`. Unsourced numbers never enter the deliverables.

Sources checked so far: MAAIF maize manual, MAAIF beans manual, a finger millet report, and a 2022 Rakai/Nakasongola planting-date trial. Full citations go in `../SOURCES.md`.
